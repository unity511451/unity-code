# Unity Code

Консольный AI-ассистент для программирования. Один файл, без внешних зависимостей (только stdlib). Python 3.10+.

## Что умеет

- Работа с OpenAI, Anthropic, Ollama, любыми OpenAI-совместимыми API
- Стриминг ответов (текст печатается по мере генерации)
- Подсветка кода (Python, JavaScript, C++)
- Нумерация и сохранение блоков кода (можно скопировать в буфер командой `/copy N`)
- Работа с файлами: `/file`, `/write`, `/run`, `/ls`
- Git: `/git status`, `/git diff`, `/git log`, `/git branch`
- Multimodal: отправка изображений (`/img PATH`)
- Агент: планирование и пошаговое выполнение задач (`/agent TASK`)
- Плагины (папка `plugins/`)
- Tab-автодополнение путей
- Подсказка по бесплатной работе через Ollama

## Установка

Внешних зависимостей **нет**. Только Python 3.10+.

```bash
python unity.py
